# 🕌 المحرون - منصة تحفيظ القرآن الكريم

## 📖 نظرة عامة

المحرون هو نظام متكامل لتحفيظ القرآن الكريم يجمع بين المعلمين والطلاب في بيئة تعليمية إسلامية متطورة. يوفر النظام مكالمات فيديو عالية الجودة ونظام دردشة شامل مع تصميم إسلامي أنيق.

## ✨ الميزات الرئيسية

### 🎥 نظام المكالمات المتطور
- **مكالمات فيديو عالية الجودة** مع تقنية WebRTC
- **مشاركة الشاشة** لعرض المصحف والمواد التعليمية
- **تحكم كامل** في الكاميرا والميكروفون
- **مؤشرات جودة الاتصال** في الوقت الفعلي
- **واجهة إسلامية أنيقة** مع تصميم متجاوب

### 💬 نظام الدردشة الشامل
- **رسائل فورية** بين المعلمين والطلاب
- **دعم الإيموجي** والرموز التعبيرية
- **رفع الملفات والصور** لمشاركة المواد التعليمية
- **تسجيل الرسائل الصوتية** لتحسين التواصل
- **تكامل مع Firebase** لحفظ المحادثات

### 🔧 لوحة التحكم الإدارية
- **إدارة المستخدمين** (معلمين وطلاب)
- **نظام الأكواد والاشتراكات**
- **إحصائيات مفصلة** عن الاستخدام
- **إعدادات النظام** المتقدمة
- **نظام الإشعارات** المتكامل

## 🛠️ التقنيات المستخدمة

### Frontend
- **Next.js 15** - إطار عمل React متطور
- **TypeScript** - لكتابة كود آمن ومنظم
- **Tailwind CSS** - للتصميم السريع والمتجاوب
- **Framer Motion** - للرسوم المتحركة الأنيقة
- **Lucide React** - مكتبة الأيقونات الحديثة

### Backend & Database
- **Firebase** - قاعدة البيانات والمصادقة
- **Node.js** - خادم الإشارات للمكالمات
- **Socket.io** - للاتصال الفوري
- **WebRTC** - لمكالمات الفيديو المباشرة

### الأمان والحماية
- **JWT Tokens** - للمصادقة الآمنة
- **CSRF Protection** - حماية من الهجمات
- **Rate Limiting** - منع إساءة الاستخدام
- **Input Sanitization** - تنظيف المدخلات

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js 18+ 
- npm أو yarn
- حساب Firebase
- Git

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/almaherun/almaheron_realy.git
cd almaheron_realy
```

2. **تثبيت التبعيات**
```bash
# تثبيت تبعيات العميل
npm install

# تثبيت تبعيات الخادم
cd server && npm install && cd ..
```

3. **إعداد متغيرات البيئة**
```bash
cp .env.local.example .env.local
```

4. **تحديث إعدادات Firebase**
قم بتحديث الملف `.env.local` بإعدادات Firebase الخاصة بك:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
# ... باقي الإعدادات
```

5. **تشغيل النظام**
```bash
# تشغيل النظام المتكامل (العميل + الخادم)
npm run start:system

# أو تشغيل كل جزء منفصل
npm run dev              # العميل
npm run start:signaling  # خادم الإشارات
```
