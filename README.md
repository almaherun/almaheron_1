# 🕌 الماهرون - منصة تعليمية متطورة

## 📖 نظرة عامة

الماهرون هو نظام تعليمي متكامل يجمع بين المعلمين والطلاب في بيئة تعليمية متطورة. يوفر النظام مكالمات فيديو مجانية 100% باستخدام Jitsi Meet ونظام إدارة شامل مع تصميم عصري وأنيق.

## ✨ الميزات الرئيسية

### 🎥 نظام المكالمات المجاني 100% (Jitsi Meet)
- **مكالمات فيديو مجانية تماماً** بدون حدود زمنية
- **جودة عالية HD** مع تشفير end-to-end
- **سهولة الاستخدام** - نقرة واحدة للاتصال
- **لا توجد تكاليف إضافية** - مجاني بالكامل
- **واجهة عصرية** مع تصميم متجاوب
- **استقرار عالي** - يعمل 24/7 بدون توقف

### 💬 نظام الدردشة والتواصل
- **رسائل فورية** بين المعلمين والطلاب
- **دعم الإيموجي** والرموز التعبيرية
- **رفع الملفات والصور** لمشاركة المواد التعليمية
- **إشعارات فورية** للرسائل الجديدة
- **تكامل مع Firebase** لحفظ المحادثات

### 🔧 لوحة التحكم الإدارية
- **إدارة المستخدمين** (معلمين وطلاب)
- **نظام الأكواد والاشتراكات**
- **إحصائيات مفصلة** عن الاستخدام
- **إعدادات النظام** المتقدمة
- **نظام الإشعارات** المتكامل

## 🛠️ التقنيات المستخدمة

### Frontend
- **Next.js 14** - إطار عمل React متطور
- **TypeScript** - لكتابة كود آمن ومنظم
- **Tailwind CSS** - للتصميم السريع والمتجاوب
- **Framer Motion** - للرسوم المتحركة الأنيقة
- **Lucide React** - مكتبة الأيقونات الحديثة

### Backend & Database
- **Firebase** - قاعدة البيانات والمصادقة
- **Jitsi Meet** - نظام المكالمات المجاني (جديد!)
- **Firestore** - قاعدة البيانات السحابية
- **Firebase Auth** - نظام المصادقة الآمن

### الأمان والحماية
- **Firebase Security Rules** - قواعد الأمان المحكمة
- **JWT Tokens** - للمصادقة الآمنة
- **Input Validation** - التحقق من صحة المدخلات
- **Role-based Access** - صلاحيات حسب نوع المستخدم

## 🚀 التثبيت والتشغيل

### المتطلبات الأساسية
- Node.js 18+
- npm أو yarn
- حساب Firebase
- Git

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/almaherun/almaheron_1.git
cd almaheron_1
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **إعداد متغيرات البيئة**
```bash
cp .env.example .env.local
```

4. **تحديث إعدادات Firebase**
قم بتحديث الملف `.env.local` بإعدادات Firebase الخاصة بك:
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

5. **تشغيل النظام**
```bash
npm run dev
```

## 🔥 إعداد Firebase

### 1. إنشاء مشروع Firebase
- اذهب إلى [Firebase Console](https://console.firebase.google.com)
- أنشئ مشروع جديد
- فعّل Authentication و Firestore

### 2. رفع قواعد Firestore
```bash
firebase deploy --only firestore:rules
```

### 3. رفع فهارس قاعدة البيانات
```bash
firebase deploy --only firestore:indexes
```
